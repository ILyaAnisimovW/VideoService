# AGENTS.md

## Проект
Видеосервис на Java / Spring Boot. Целевая архитектура: модульный API, отдельный FFmpeg worker, PostgreSQL, RabbitMQ и S3-совместимое хранилище. Документация описывает проект MVP; проверяй, что уже реализовано в коде.

## Документация по задаче
- Архитектура и границы модулей: `docs/architecture/`.
- Данные, состояния и права: `docs/domain/`; взаимодействия: `docs/scenarios/`.
- HTTP и события: `docs/api/openapi.yaml`, `docs/api/asyncapi.yaml`, `docs/api/events.md`.

## Правила разработки
- Сохраняй границы модулей; используй их публичные интерфейсы вместо чужих repositories.
- API владеет состоянием видео; worker не обращается к PostgreSQL напрямую.
- Обработку выполняй асинхронно. Учитывай повторную доставку, outbox, версии обработки и lease.
- Не принимай устаревший результат и не публикуй удалённое видео.
- Проверяй владельца и доступ на сервере; приватность распространяется на плейлисты и сегменты.
- Изменения API, событий и данных согласовывай с документацией; изменения схемы БД оформляй миграциями.
- Используй существующий стиль, зависимости и сборку проекта. Не добавляй инфраструктуру без необходимости для задачи.
- Не сохраняй секреты, JWT и подписанные URL в Git или логах.

## Проверка и отчёт
Запускай проверки, относящиеся к изменению, через существующий build wrapper. При изменении контрактов запускай `python scripts/validate_docs.py`, если комплект документации подключён. В ответе кратко укажи изменения, выполненные проверки и оставшиеся ограничения; не заявляй успешную проверку без запуска.
