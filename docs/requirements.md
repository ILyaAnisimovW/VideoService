# Требования и границы MVP

Статус: лимиты заложены в код backend MVP; это не измеренные возможности системы. Сквозной стенд и нагрузочные показатели ещё не подтверждены.

## Пользовательские сценарии

| ID | Сценарий | Критерий готовности |
|---|---|---|
| UC-01 | Автор загружает видео | Обрыв соединения не требует повторно загружать успешные части |
| UC-02 | Система обрабатывает видео | READY выставляется после проверки полного набора обязательных assets |
| UC-03 | Зритель смотрит видео | Доступ проверяется для плейлистов; сегменты защищены короткими ссылками |
| UC-04 | Автор меняет приватность | Новый запрос просмотра использует актуальные права |
| UC-05 | Модератор блокирует видео | Новые сессии и новые плейлисты недоступны |
| UC-06 | Автор удаляет видео | Метаданные скрываются сразу; файлы удаляются асинхронно |
| UC-07 | Worker падает | Задание восстанавливается; поздний результат не публикуется |

## Предлагаемые ограничения

| Параметр | Значение |
|---|---|
| Максимальный исходник | 2 GiB: 2 147 483 648 байт |
| Максимальная длительность после ffprobe | 30 минут |
| Поддерживаемый вход | Контейнеры MP4, MOV, WebM; фактические потоки проверяются worker |
| Размер части | 16 MiB; последняя часть может быть меньше |
| Срок сессии загрузки | 24 часа |
| Срок ссылки на загрузку части | 10 минут, не дольше срока сессии |
| Playback-сессия | 15 минут |
| Ссылка на сегмент | До 5 минут, не дольше playback-сессии |
| Lease обработки | 60 секунд; heartbeat каждые 20 секунд |
| Лимит одной попытки | 20 минут; lease нельзя продлевать бесконечно |
| Попытки задания | До 3, включая первую |
| HLS | H.264 / AAC, VOD; до 360p, 720p, 1080p без увеличения исходного разрешения |
| Исходник ниже 360p | Одна rendition не выше исходного разрешения; запрета только из-за малого разрешения нет |
| Access JWT | 1 час; refresh/logout не входят в этот контракт MVP |
| Idempotency-Key | Результат сохраняется 24 часа после завершения операции |

Ограничение 20 минут на обработку — защитный timeout. Его пригодность для выбранного CPU и исходников проверяется экспериментом.

## За границами

Live streaming, платежи, ML-рекомендации, DRM, комментарии, реакции, пользовательские жалобы, email verification/recovery. Email Provider в C4 остаётся планируемой интеграцией. Модератор в MVP блокирует видео через прямой административный сценарий.

## Цели проверки

Для каталога выбрать стенд и профиль нагрузки, затем зафиксировать p95, частоту ошибок и RPS. Для обработки измерять время по длительности/разрешению исходника и возраст задания. До замера не заявлять производительность или доступность.

Подписанные URL ограничивают доступ, но не запрещают пользователю сохранить уже полученные данные. После блокировки ранее выданный URL сегмента может работать до своего expiresAt; удалённый из CDN или браузера кэш также нельзя отозвать этим механизмом.
